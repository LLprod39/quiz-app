# Quiz App

Интерактивная платформа для двух форматов: персонального праздника о близком человеке и тематического квиз-баттла на любую тему. Организатор управляет игрой с телефона, игроки отвечают без регистрации, а телевизор показывает общий игровой экран.

В персональном формате доступны анкета и особые вопросы с выбором героя. В тематическом баттле организатор задаёт тему — например, кино, музыку, спорт или науку — и проводит личную либо командную игру без роли героя.

## Быстрый запуск для разработки

Требуются Node.js 20+ и Python 3.12+.

```powershell
cd apps/api
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
.\.venv\Scripts\uvicorn app.main:app --reload --port 8000
```

Во втором окне:

```powershell
npm install
npm run dev
```

Откройте `http://localhost:5173`. Демо-вход организатора: `organizer@example.local` / `celebrate`.

При первом запуске API создаёт демонстрационное мероприятие «Вечер в честь Лены» и три вопроса. В разделе «Мои квизы» можно хранить любое количество персональных праздников и тематических квиз-баттлов, переключаться между ними и запускать каждый повторно без потери настроек.

Редактор автоматически сохраняет незавершённый вопрос как локальный черновик и восстанавливает его после обновления страницы. Кнопка «Быстрый тест» добавляет до пяти готовых вопросов разных типов, чтобы сразу проверить полный игровой цикл.

На телевизионной странице `/screen/<код>` озвучивается только текст вопроса — варианты ответов синтезатору не передаются. Каждый новый вопрос читается один раз, текущий можно повторить вручную, а переключатель запоминается только в браузере телевизора.

Если настроен Microsoft Azure Speech, аудио запрашивается через API приложения: секретный ключ остаётся на сервере и никогда не попадает в браузер. Без ключа, при ошибке Azure или отсутствии интернета автоматически используется локальный Web Speech API с предпочтением установленного русского голоса. Для Azure задайте серверные переменные окружения:

```env
AZURE_SPEECH_KEY=<ключ ресурса Speech>
AZURE_SPEECH_REGION=westeurope
AZURE_SPEECH_VOICE=ru-RU-SvetlanaNeural
```

`AZURE_SPEECH_REGION` должен совпадать с регионом ресурса. Голос необязателен: по умолчанию используется `ru-RU-SvetlanaNeural`. Не добавляйте ключ в переменные `VITE_*` или клиентский код. По состоянию на август 2026 года тариф [Azure Speech Free F0](https://azure.microsoft.com/en-us/pricing/details/speech/) включает 0,5 млн символов нейронного TTS в месяц, а [лимит real-time TTS](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-services-quotas-and-limits) составляет 20 транзакций за 60 секунд. Azure Speech является облачной службой и требует интернет; полностью автономным остаётся браузерный fallback.

## Каталог тематических квизов

Публичный каталог доступен по адресу `/quizzes`. В стартовую библиотеку входят три автономных баттла по 20 вопросов: Marvel, космос и мировое кино. У каждого набора есть собственный адрес `/quiz/<slug>`, название, знак, описание, тексты интерфейса и цветовая схема.

Организатор может выбрать набор в разделе «Каталог шаблонов». Установка добавляет новый самостоятельный квиз в библиотеку и не изменяет уже сохранённые квизы. Каждый запуск создаёт отдельную комнату, поэтому один набор можно проводить снова и снова, сохраняя результаты всех игр. Вопросы пакетов хранятся локально, поэтому их можно запускать без обращения к внешнему API.

Источники и лицензии контента указаны на странице каждого набора и собраны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Запуск в локальной сети без интернета

```powershell
docker compose -f infra/compose.lan.yml up --build
```

Приложение откроется на `http://<IP-ноутбука>`. Все устройства должны быть в одной Wi-Fi сети; на роутере должен быть отключён client isolation.

## Облачный профиль

Скопируйте `infra/env/cloud.example.env` в защищённый `.env`, заполните домен и секреты, затем:

```powershell
docker compose --env-file .env -f infra/compose.cloud.yml up --build -d
```

Для публичного запуска TLS должен завершаться перед Nginx (например, в облачном балансировщике или Caddy). Подробности: [docs/deployment.md](docs/deployment.md).

## Проверки

```powershell
npm test
npm run build
cd apps/api
pytest
```

API документация доступна на `http://localhost:8000/docs`, healthcheck — `/api/health`.
