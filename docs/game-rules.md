# Правила игры

- Правильность важнее скорости: сначала сравнивается число правильных, затем суммарное время только правильных ответов.
- Общий рейтинг скрыт до финала; участник видит лишь свой результат и место после раскрытия.
- Ответ принимается один раз. Повтор запроса возвращает сохранённый ответ.
- Поздно подключившийся начинает со следующего вопроса.
- В команде ответ отправляет капитан, результат и место общие.
- Пропуск и отсутствие ответа дают ноль без штрафа.
- Отменённый вопрос исключается из подсчёта; изменение правильного ответа пересчитывает результаты.
- Точный множественный ответ требует совпадения всего набора.
- Текст нормализуется по регистру, пробелам, знакам и `ё/е`; спорное решение может исправить организатор.
- В вопросе героя его собственный ответ не приносит ему балл.
