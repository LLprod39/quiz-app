# Архитектура

`apps/web` содержит единое React-приложение с маршрутами организатора, телевизора, игрока и персональной анкеты героя. `apps/api` — FastAPI-сервис и единственный источник истины для состояния комнаты, таймера, проверки ответов и рейтинга.

Событие имеет формат `celebration` или `battle`. Персональный праздник хранит имя и анкету героя, а тематический баттл — произвольную тему. Раунды, вопросы, личный и командный режимы, эфир и результаты переиспользуются обоими форматами; недоступные для баттла функции героя дополнительно блокируются API.

Изменения игры проходят через серверную машину состояний. Каждая команда увеличивает `state_version`; клиенты получают WebSocket-снимок и отбрасывают старые версии. Ответы идемпотентны по `request_id` и уникальны для участника или команды.

В LAN-профиле медиа и PostgreSQL находятся на том же компьютере. В cloud-профиле интерфейс хранения допускает замену локального каталога на S3, а Redis включён для последующего распределённого WebSocket fan-out.
