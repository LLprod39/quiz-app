# Развёртывание и репетиция

## LAN

1. Назначьте компьютеру постоянный локальный IP.
2. Запустите `infra/compose.lan.yml`.
3. Проверьте `http://<локальный-ip>/api/health` с телефона.
4. Убедитесь, что телефоны видят друг друга и отключён client isolation.
5. Откройте экран «Репетиция» и проверьте WebSocket, задержку, звук, fullscreen и медиа.

Интернет после запуска не нужен. Не выключайте компьютер и не переводите его в сон во время игры.

## Cloud

Используйте длинный `SECRET_KEY`, отдельный пароль PostgreSQL, HTTPS и внешний backup volume. Прокси должен передавать `Upgrade`/`Connection` для `/ws/`. Для нескольких API-инстансов подключите Redis pub/sub вместо локального реестра соединений.

## Резервные копии

`infra/scripts/backup.ps1` сохраняет дамп PostgreSQL, `restore.ps1` восстанавливает его в выбранную БД. Медиа-каталог резервируется отдельно.
